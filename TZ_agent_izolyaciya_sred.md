# Техническое задание для AI-агента: аудит ПК, изоляция «российского» софта и проверка анонимности

## Общая цель
Провести полный аудит ПК на предмет сертификатов Минцифры России и следов мессенджера MAX, перенести всё связанное с ними (сертификаты, файлы, ярлыки, службы) в отдельную изолированную среду на диске D, проверить систему на утечки анонимности и настроить максимально доступный уровень приватности, сохранив при этом удобный доступ пользователя к Госуслугам и другим нужным сервисам через эту изолированную среду.

Важно: ничего не скачивать из интернета без явной команды. Если что-то нужно установить — агент создаёт папку на диске D и устанавливает туда **уже имеющиеся у пользователя** установочные файлы (искать их на всех дисках перед тем, как просить скачать что-либо заново).

---

## Этап 1. Полное сканирование дисков

**Задача:** найти все следы сертификатов Минцифры и мессенджера MAX на всех локальных дисках (C, D, и т.д.), включая скрытые и системные папки.

### Что искать
- Сертификаты с именами `Russian Trusted Root CA`, `Russian Trusted Sub CA`, `Минцифры`, `Мин.цифры`.
- Хранилища: `Cert:\LocalMachine\Root`, `Cert:\LocalMachine\CA`, `Cert:\CurrentUser\Root`, `Cert:\CurrentUser\CA`, а также хранилища Firefox (`cert9.db`) и Chrome/Edge (используют системное хранилище Windows).
- Установочные файлы, ярлыки, папки MAX: `%AppData%\MAX`, `%LocalAppData%\MAX`, `%ProgramFiles%\MAX`, реестр `HKCU\Software\MAX`, `HKLM\Software\MAX`, автозагрузка (`Task Scheduler`, `Startup`, службы Windows).
- Любые `.crt`, `.cer`, `.pem`, `.p7b` файлы с упоминанием «Russian Trusted» в метаданных или пути.

### Инструменты и команды
Скрипт для PowerShell (запуск от администратора) для поиска сертификатов:
```powershell
Get-ChildItem Cert:\LocalMachine, Cert:\CurrentUser -Recurse | Where-Object { $_.Subject -match "Russian Trusted" -or $_.Issuer -match "Russian Trusted" } | Select-Object Subject, Issuer, PSParentPath, Thumbprint | Export-Csv "D:\Audit\certs_found.csv" -NoTypeInformation
```

Поиск файлов MAX и остатков установки по всем дискам:
```powershell
Get-PSDrive -PSProvider FileSystem | ForEach-Object {
  Get-ChildItem -Path $_.Root -Recurse -Filter "*MAX*" -ErrorAction SilentlyContinue
} | Export-Csv "D:\Audit\max_files_found.csv" -NoTypeInformation
```

Результат сканирования сохранить в отчёт `D:\Audit\report.md` со списком найденных объектов, путей и рекомендуемых действий (удалить / перенести / игнорировать).

### Справочные материалы
- Гайд по поиску и удалению сертификатов Минцифры в Windows: [aganin.org/78](https://aganin.org/78)
- Разбор, где искать сертификаты и как проверить их наличие: [remontka.pro — установка сертификатов Минцифры](https://remontka.pro/mintsifry-certificates-install/)
- Обсуждение удаления сертификатов Минцифры (Хабр Q&A): [qna.habr.com/q/1253218](https://qna.habr.com/q/1253218)

## Этап 2. Создание изолированной среды на диске D

**Задача:** развернуть виртуальную машину (или, как облегчённый вариант, песочницу Sandboxie-Plus), полностью размещённую на диске D, куда будут перенесены сертификаты Минцифры, MAX и любой связанный «российский» софт (Госуслуги, банк-клиенты, СБП-приложения и т.п.).

### Рекомендуемый вариант — виртуальная машина (максимальная изоляция)
1. Проверить, установлен ли уже VirtualBox или другой гипервизор на ПК (не скачивать повторно, если уже есть инсталлятор).
2. При установке VirtualBox указать путь по умолчанию для виртуальных машин на диск D:
   `File → Preferences → General → Default Machine Folder → D:\VM`
3. Создать новую виртуальную машину (Windows или лёгкий Linux) с диском фиксированного размера 40–60 ГБ, файл `.vdi` разместить на `D:\VM\Isolated`.
4. Внутрь этой ВМ:
   - Установить найденные на Этапе 1 сертификаты Минцифры.
   - Установить MAX (если инсталлятор уже есть на диске — использовать его, не скачивать).
   - Настроить браузер для доступа к Госуслугам и другим сервисам, требующим эти сертификаты.
5. Из основной (хостовой) системы эти сертификаты и MAX **полностью удалить** после переноса — см. Этап 3.

Гайды по установке и настройке VirtualBox с диском на D:
- Пошаговая инструкция по VirtualBox: [adminvps.ru — инструкция по VirtualBox](https://adminvps.ru/blog/instrukcziya-po-zapusku-virtualnyh-mashin-s-virtualbox-ot-ustanovki-do-nastrojki/)
- Как перенести папку виртуальных машин на диск D: [форум VirtualBox — Installing virtual disk other than in OS disk drive](https://forums.virtualbox.org/viewtopic.php?t=85860)
- Базовая инструкция от Nic.ru: [nic.ru — как пользоваться VirtualBox](https://www.nic.ru/help/kak-pol6zovat6sya-virtualbox-poshagovaya-instrukciya_11257.html)

### Альтернативный лёгкий вариант — Sandboxie-Plus (песочница без перезагрузки)
Подходит, если не нужна полная ВМ, а достаточно изолировать процесс браузера/MAX от остальной системы файлов и реестра.
1. Установить Sandboxie-Plus, при установке выбрать папку `D:\Sandboxie`.
2. Создать отдельный бокс `IsolatedGosuslugi`, в его настройках (`Sandbox Options → Resource Access`) указать корневой путь на диск D:
   `FileRootPath=D:\Sandboxie\IsolatedGosuslugi`
3. Все сертификаты и MAX ставить и запускать только внутри этого бокса.

Важное ограничение: Sandboxie изолирует файлы/реестр, но **не изолирует ядро системы и сеть** так же полно, как ВМ — учитывать при оценке анонимности.

Гайды:
- Официальная инструкция по установке Sandboxie-Plus: [Adam the Automator — How to Install Sandboxie](https://adamtheautomator.com/sandboxie/)
- Обсуждение установки на внешний/другой диск: [GitHub issue — Install on External drive possible?](https://github.com/sandboxie-plus/Sandboxie/issues/4238)
- Migration Guide и справочник по настройкам: [Sandboxie-Plus Migration Guide](https://sandboxie-plus.github.io/sandboxie-docs/Content/PlusMigrationGuide.html)
- FAQ по безопасности Sandboxie: [Sandboxie-Plus FAQ](https://sandboxie-plus.com/sandboxie/frequentlyaskedquestions/)

## Этап 3. Очистка основной системы

После успешного переноса в изолированную среду и проверки, что доступ к нужным сервисам (Госуслуги и т.д.) работает **внутри** ВМ/песочницы:

1. Удалить сертификаты Минцифры из `certmgr.msc` (пользовательское хранилище) и `certlm.msc` (системное хранилище) — разделы «Доверенные корневые центры сертификации» и «Промежуточные центры сертификации».
2. Удалить MAX через «Параметры → Приложения», затем вручную очистить остаточные папки и ключи реестра, найденные на Этапе 1.
3. Проверить автозагрузку (`Ctrl+Shift+Esc → Автозагрузка`, `taskschd.msc`) на предмет оставшихся служб MAX.
4. Повторить сканирование из Этапа 1, чтобы убедиться, что основная система «чистая».

## Этап 4. Проверка ПК на анонимность

**Задача:** прогнать и основную систему, и изолированную среду через набор онлайн-инструментов проверки цифрового отпечатка, сравнить результаты, зафиксировать в отчёте `D:\Audit\anonymity_report.md`.

### Инструменты для проверки (запускать из браузера)
- [Whoer.net](https://whoer.net) — общий приватность-скор (IP, DNS, WebRTC, часовой пояс, метаданные браузера).
- [BrowserLeaks.com](https://browserleaks.com) — детальные тесты по WebRTC, Canvas, WebGL, шрифтам, cookies.
- [Iphey.com](https://iphey.com) — комплексная оценка «похожести на реального пользователя» и обнаружение анти-детект признаков.
- [PixelScan.net](https://pixelscan.net) — тест WebRTC/DNS-утечек и проверка на бот-детект.
- [AmIUnique.org](https://amiunique.org) — оценка уникальности отпечатка браузера (canvas, шрифты и т.д.).

### Что проверять и фиксировать
- Совпадает ли реальный IP/DNS с ожидаемым (нет ли утечки через WebRTC).
- Часовой пояс и язык системы vs геолокация по IP.
- Уникальность fingerprint (User-Agent, разрешение экрана, список шрифтов, Canvas/WebGL hash).
- Результат отдельно для основной системы и отдельно для изолированной среды — они должны отличаться, чтобы подтвердить эффективность изоляции.

Дополнительный обзорный материал по выбору инструментов проверки: [SOAX — 8 best fingerprint detection tools](https://soax.com/blog/best-browser-checking-tools), [BitBrowser — Whoer.net alternatives](https://www.bitbrowser.net/news/top-10-browser-fingerprinting-test-tools).

## Этап 5. Настройка максимально доступного уровня анонимности

В рамках изолированной среды (ВМ или песочница) агенту нужно применить настройки, снижающие фингерпринт без нарушения работы Госуслуг и банковских сервисов (эти сервисы часто требуют «нормальный» отпечаток, поэтому агрессивные анти-детект настройки внутри неё не нужны — задача изоляции важнее маскировки):

- Отключить WebRTC в браузере ВМ (`about:config → media.peerconnection.enabled = false` для Firefox, либо расширение для Chrome/Edge).
- Синхронизировать часовой пояс и язык системы ВМ с реальным местоположением (Frankfurt am Main), чтобы не вызывать подозрений у сервисов, требующих реальную геолокацию (Госуслуги, банкинг).
- Использовать в изолированной среде отдельный, не связанный с основным профилем браузера аккаунт/куки-хранилище.
- Не устанавливать в изолированной среде лишний софт, который не требуется напрямую для MAX/Госуслуг — минимизировать поверхность идентификации.

## Итоговый отчёт агента должен содержать

1. `D:\Audit\report.md` — список найденных сертификатов и файлов MAX, что было перенесено/удалено.
2. `D:\Audit\anonymity_report.md` — сравнение fingerprint основной системы и изолированной среды (скриншоты/данные с Whoer, BrowserLeaks, Iphey, PixelScan, AmIUnique).
3. Пошаговая инструкция, как пользователю заходить в изолированную среду для доступа к Госуслугам/MAX после завершения работ (ярлык на рабочем столе, логин в ВМ, путь запуска).
4. Подтверждение, что на основной системе сертификаты Минцифры и MAX отсутствуют (по результатам повторного сканирования).
